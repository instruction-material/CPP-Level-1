# CPPF7 Project 2: Grid Statistics

Use a 2D `std::vector` to compute statistics from a grid.

Practice goals:
- print a rectangular grid clearly
- compute row totals
- compute column totals
- compute the main diagonal total
- find the largest value and its location

Extension ideas:
- add input validation for non-rectangular grids
- compute the anti-diagonal total
- let the user choose which statistic to print

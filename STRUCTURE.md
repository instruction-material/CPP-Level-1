# CPP-Level-1 Structure

This repository backs `C++ Level 1`. It currently mixes legacy direct-source
projects with generated supplemental wrappers.

Active public folders stay at the repository top level. Folders not linked by
the live catalog on 2026-05-14 were moved to `_archived-unlinked/`.

New C++ Level 1 material uses the existing `CPPF*` project folders. Reviewed
assignments have nested `starter` and `solution` folders linked separately by
the catalog. Preserve original filenames. A legacy root entry may forward to
a verified reference; it must not be presented as learner starter code.
Unlinked alternate top-level projects require an explicit purpose and mapping.

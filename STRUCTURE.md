# CPP-Level-1 Structure

This repository backs `C++ Level 1`. It currently mixes legacy direct-source
projects with generated supplemental wrappers.

Active public folders stay at the repository top level. Folders not linked by
the live catalog on 2026-05-14 were moved to `_archived-unlinked/`.

New C++ Level 1 material should use `CPPF*` or an existing course prefix and
should avoid unlinked alternate `Starter`, `Reference`, or `Supplemental`
variants beside the active course surface.

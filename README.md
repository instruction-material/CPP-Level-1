# C++ Level 1

This repo keeps one directory per project/build and does not track local build
artifacts or IDE metadata.

Cleanup rules applied here:
- generated binaries such as `main`
- macOS debug bundles such as `*.dSYM`
- local IDE folders such as `.idea/`
- local CMake build trees such as `cmake-build-debug/`

This repo now keeps only the C++ Level 1 materials:
- `CPPF*` main reference and project folders
- `CPP-*` C++ supplemental folders
- `CPP_practice` and `CPP_Structs-Example`

The C foundations build sequence that was previously mixed into this repo now
lives in `instruction-material/C-Level-1-C-Fundamentals`.
